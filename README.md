🎮 Medio Tateti

A console-based strategy board game developed in Java for two players.

This project was created as part of the Programming II course at ORT University Uruguay, focusing on object-oriented design, game logic implementation, data structures, and user interaction through the console.

🎯 Game Rules

Players alternate turns placing or rotating pieces on a 3×6 board.

⚪ White player aims to create three aligned "O" shapes
⚫ Black player aims to create three aligned "X" shapes
Pieces can be placed or inverted during a turn
Alignments can be horizontal, vertical, or diagonal
The first player to achieve their objective wins

The game includes several special commands such as:

Help system
Board visualization controls
Match termination
Draw agreements
